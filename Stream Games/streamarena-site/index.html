Straight answers

The questions streamers actually ask.

Do my viewers have to sign up for anything?

No. They type in chat. That is the whole interaction, and it is the point.

Do I have to install software?

No. One browser source URL in OBS, added once. Everything else runs on our side.

Is this gambling?

No. Viewers never stake money. There are no deposits, no withdrawals, and no cash out. Points are engagement scoring with no monetary value and no way to redeem them. StreamArena sits beside gambling content, it is not a gambling operator.

What happens when my overlay drops mid stream?

It reconnects and resyncs on its own. OBS browser sources drop constantly, so the overlay is built to expect it.

Will the bot spam my chat?

It stays quiet by default and only speaks when something goes wrong. Four settings: off, errors only, batched summaries, or every request.

What if chat spells the slot name wrong?

Gates, gates of olympus, and gatez all land on the same slot. When it genuinely cannot tell, it asks the viewer instead of guessing.

Does it work on Twitch?

Kick first. The platform layer is separated from the games, so Twitch is an addition rather than a rewrite.
