# Screenshots Directory

This directory contains screenshots for the README file.

## Required Screenshots:

1. **home.png** - Home page with hero section and specials carousel
2. **menu.png** - Menu system with category filtering
3. **cart.png** - Shopping cart with items and order summary
4. **auth.png** - Authentication pages (sign up/login)
5. **mobile.png** - Mobile responsive view

## Screenshot Guidelines:

- **Resolution**: 1920x1080 or higher for desktop views
- **Mobile**: 375x812 (iPhone X) for mobile screenshots
- **Format**: PNG for best quality
- **Content**: Show actual app functionality with sample data
- **Browser**: Use Chrome/Safari for clean browser chrome

## How to Take Screenshots:

1. **Desktop**: Use browser developer tools to set viewport
2. **Mobile**: Use device simulation in dev tools
3. **Full Page**: Capture key sections that showcase features
4. **Clean Data**: Use realistic sample food items and user data

## Naming Convention:

- Use lowercase with hyphens: `home-page.png`
- Be descriptive: `cart-with-items.png`
- Include device type if needed: `mobile-menu.png`
